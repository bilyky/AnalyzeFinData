# PROD — OceanView context pack in the evening pipeline + watchdog gate (#177) — 2026-10-08

**What it changes**
- `daily_task` (the 17:00 Evening task) builds the OceanView context pack after the report and
  backup sync, **before** the RapidAPI repair pass. The broker read needs a same-day ET token,
  whose day ends at 21:00 PT, and the repair can run for hours.
- Every build writes its verdict to `Data\oceanview_context_status.json`: health, source, time
  and warnings. No accounts, positions or sleeves.
- The hourly watchdog emails **"🛑 Project AETHER: OceanView context pack alert"** when the last
  build is `failed` (CRITICAL) or the status is more than 30 h old (WARNING). It's quiet for
  `ok` / `degraded`, and before the first build. Each distinct alert goes out at most once a day.
- Weekends: the pack accepts Friday's cached snapshot (up to 72 h), so a normal weekend
  doesn't alert.

The broker read is ban-safe: `etrade.keep_alive` only renews a same-day token and never
opens a browser.

Paths are relative to the PROD checkout `C:\Develop\StockTrading\AnalyzeFinData`;
`python` = `venv_new\Scripts\python.exe`.

## 0. Preconditions

- **#176 is already on main** (merged into #177). The Evening task limit is 420 min. #177's
  worst case is 388 min (the pack adds 5 min); the guard test pins it.
- **The morning reauth must work.** The pack needs a same-day E*TRADE token at ~17:30 PT.
  If PROD has no valid token by then, the pack builds as `failed` and the watchdog sends one
  CRITICAL a day. That's intended ("don't advise on stale numbers").
- Optional: `oceanview.sleeves` in `config.json` (#170) for sleeve labels. Without it the
  pack still builds.

## 2. Verify after the first evening run (~17:30–18:00 PT)

```
type Data\oceanview_context_status.json
findstr /L /C:"OceanView context pack" Data\logs\aether.log
```

- The status file exists, with `"health": "ok"` (or `degraded` with warnings such as
  placeholder-heavy or missing-OHLCV symbols) and `"source": "live"`.
- The log shows `OceanView context pack: health=... source=live ...`, logged **before** the
  RapidAPI summary lines (`[RapidAPI] ... need repair` / `Done:`).
- No pack alert email. If one arrives with `CRITICAL ... FAILED`, its text says why. Usually
  it's no same-day token (check the morning reauth).
