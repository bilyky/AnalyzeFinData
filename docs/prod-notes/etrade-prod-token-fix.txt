2. HOW THE DAILY E*TRADE TOKEN WORKS (why it breaks)
=====================================================================
- E*TRADE tokens expire at midnight US Eastern (9 PM Pacific). Renew can NOT save an
  expired token; a new login (TOTP, headless browser) is required once per ET day.
- A token that gets no requests for 2 hours goes INACTIVE (returns 401). One renew call
  reactivates it. Since #144 the code does that automatically before giving up.
- The automated login is protected by a circuit breaker: each failed attempt adds a
  cooldown (15 -> 30 -> 60 ... min) and after 3 consecutive failures it hard-blocks and
  emails you. A human must clear it (section 5).

Scheduled jobs that touch E*TRADE (Windows Task Scheduler on PROD):
  AETHER_PreFlight_Audit        daily 9:30 PM   preflight_validator.py --email (briefing email)
  AnalyzeFinData_ETrade_Reauth  daily 5:15 AM   server.py etrade-reauth --scheduled
                                                (defined in watchdog.py; check it is installed)
  AnalyzeFinData_Morning        daily 5:30 AM   autonomous_pipeline.py (runs preflight first;
                                                aborts the day if preflight fails on a weekday)
  Project_AETHER_Watchdog       hourly          watchdog.py (calls the same re-auth path)

4. SWITCHES (environment variables; config.json "etrade" section in brackets)
=====================================================================
  AETHER_ETRADE_STORE=db                 Use the E*TRADE DB backend. DO NOT SET: it is a stub
                                         (Phase 5, not implemented). Unset = file backend.
                                         A database URL alone (DATABASE_URL / database.url)
                                         no longer selects it.
  AETHER_ETRADE_SCHEDULED_HEADLESS=0     Make the automated login run headful (visible).
                                         Default = headless. Only the env var works
                                         (there is no config.json key for it).
  ETRADE_REAUTH_WAIT_TIMEOUT_SEC         [reauth_wait_timeout_sec, default 10] how long a
                                         second caller waits for a login already in flight.
  ETRADE_REAUTH_ALERT_THRESHOLD          [reauth_alert_threshold, default 3] failed logins
                                         before the hard block + email.
  ETRADE_TOTP_SECRET                     [totp_secret] software TOTP seed. Secret - never share.

5. STATE FILES (Data\) AND CLEARING THE BREAKER
=====================================================================
  Data\etrade_tokens.json          token + issued_date_et (ET date) + saved_at. issued_date_et
                                   must be today's ET date for the token to be usable.
  Data\etrade_reauth_state.json    breaker: consecutive_failures, last_attempt, cooldown_until
  Data\etrade_reauth.lock          present only while a login is running (a lock older than
                                   5 min is stale and is reclaimed automatically)
  Data\etrade_profile_trusted.json device-trust marker (trusted / sms_required / unseeded)

Clear the breaker (YOU decide when; back up Data\ state first per the backup policy):
  venv_new\Scripts\python.exe -c "from aether import etrade; etrade.reset_reauth_circuit_breaker('production')"
  A successful login also clears it automatically.

6. READING THE LOGS - WHAT A LINE MEANS
=====================================================================
  "Cached tokens are from a previous trading day"      -> normal after midnight ET; a login follows
  "Renew failed: HTTP 401"                             -> token expired or idle; see next lines
  "idle same-day token reactivated by renew"           -> good: no login needed (since #144)
  "previous-day token renewed but the broker rejected it" -> expired; falls through to login (#140)
  "[TOTP] Opening E*TRADE login" ... "Verifier captured" ... "token saved" -> login succeeded
  "automated re-auth attempt #N - breaker armed"        -> a login started (counts until it succeeds)
  "suppressed by circuit breaker"                       -> cooling down; wait or clear (section 5)
  "E*TRADE DB backend is not implemented yet"           -> AETHER_ETRADE_STORE=db is set (unset it),
                                                           or PROD is running code older than #144
  Preflight E*TRADE "WAIVED"                            -> ET weekend: no login on purpose (#125)
